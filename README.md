# 昇嶺電子｜產銷協同儀表板（UNEXT AI 企業創新實戰營）

本專案為「昇嶺電子：人更忙了，貨卻沒有多出去」個案之解決方案（方案 A）可互動網頁原型，單頁 HTML/CSS/JS 免安裝即可運作，並支援同機跨分頁即時推播。

## 四大核心模組

1. **📨 變更即時通知（業務 → 現場課長）**
   - 業務貼上客戶 LINE／電話／口頭原文，一鍵自動帶入客戶、機種、數量與交期並留時間戳記。
   - 課長分頁立即跳出即時推播通知，一鍵「確認收到」；換零件自動提示受影響工單並提醒停發舊料。
2. **🧰 夾具借還管理（課長／治具室）**
   - 一眼查看每件插件夾具、測試治具與飛達持有人及所在站別，逾時自動紅標提醒。
   - 一鍵借出／歸還，免填紙本、基層作業員零輸入。
3. **⚖️ 插單違約預測（老闆決策）**
   - 依真實參數（SMT 24 秒/片、實際換線 54 分、客戶乙晚 1 天罰 2%／丙罰 1%／甲無罰則）窮舉 4 條線所有插入位置。
   - 自動比對「系統建議排法 vs. 現行『甲的先做』vs. 週六加班」，同步檢核共用料庫存與夾具可用性，一鍵拍板即時更新排程。
4. **📒 每日紀錄（課長日報備註＋SMT 停機紀錄）**
   - 內建個案《資料 3》九月 26 天真實課長備註與 SMT 三類停機數據，提供停機與稼動率雙軸趨勢圖及 8 大異常自動分類排行。
   - 支援課長點選常用語 30 秒送出今日日報並即時同步至總覽。

## 展示與使用方式

- **直接開啟**：透過 GitHub Pages（啟用後於 `https://leo126791.github.io/UNEXT_1/`）或本地雙擊 `index.html`。
- **切換角色**：右上角可切換「業務」、「現場課長」、「老闆」，或於網址後加上參數：
  - 業務：`?role=sales`
  - 現場課長：`?role=lead`
  - 老闆：`?role=boss`
- **跨分頁即時推播示範**：於同一瀏覽器同時開啟兩個分頁（一頁選「業務」、一頁開 `?role=lead`），業務送出變更通知後，課長分頁右下角將即時跳出通知。
- **重置示範資料**：點擊右上角「重置示範資料」即可恢復初始工單、夾具與通知狀態。
